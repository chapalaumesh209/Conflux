# ADR 0003 V1 Scope Boundary

## Status

Accepted for V1.

## Decision

CONFLUX V1 remains focused on verified one-to-one developer networking:

- Meet
- Talk
- Connect or Next
- Revisit
- Build together

Groups, events, organisation workspaces, job-marketplace behavior, courses, content feeds, team matching, and native mobile clients are deferred.

## Expansion gate

Any proposed future mode needs evidence that the core loop is stable, safety operations are ready, beta use has validated the product, and users have explicitly demonstrated demand. The `ExpansionReadinessPolicy` encodes that gate for planning integrations; it does not authorize feature delivery by itself.
